==================================================
LINUX FILE PERMISSIONS
==================================================

Linux permissions:

r = Read    = 4
w = Write   = 2
x = Execute = 1


Example:

rwx

4 + 2 + 1 = 7

rw-

4 + 2 = 6

r-x

4 + 1 = 5

r--

4


Permissions three categories ki apply avutayi:

Owner
Group
Others


Example:

rwxr-xr--

Breakdown:

Owner  = rwx
Group  = r-x
Others = r--

19. chmod 755
-------------

Command:

Calculation:

Owner:
7 = 4+2+1 = rwx

Group:
5 = 4+1 = r-x

Others:
5 = 4+1 = r-x

Result:
rwxr-xr-x

Use:

20. chmod 644
-------------

Owner:

Group:
4 = r--

Others:
4 = r--

Result:
rw-r--r--

Use:
Normal text/config files ki common permission.


21. chmod 700
-------------

Example:

Owner  = rwx
Group  = ---
Others = ---

Result:

Use:

==================================================
GIT FILE STATES
==================================================

Untracked:
File project folder lo undi but Git inka track cheyyatledu.

Tracked:
File Git history lo already record ayyindi.

Modified:
Tracked file ni last commit tarvatha change chesam.

Staged:
Changes next commit kosam ready chesam.

Committed:
Changes Git history lo snapshot/save point ga record ayyayi.


Basic Flow:

Untracked / Modified
        ↓
     git add
        ↓
      Staged
        ↓
    git commit
        ↓
     Committed

Git diff practice

= Which files changed?

= What exactly changed inside tracked files?

Untracked:
Git ki file inka track/history lo ledu.

Modified:

tarvatha change chesam.

SSH private keys ni current session lo manage chestundi.


ssh-add ~/.ssh/id_ed25519
-------------------------
Private SSH key ni ssh-agent ki add chestundi.


ssh-add -l
----------
Agent lo loaded SSH keys list chupistundi.


ssh -T git@github.com
---------------------
GitHub SSH authentication test chestundi.


git remote -v
-------------
Current remote repository URLs chupistundi.


git remote set-url origin SSH_URL
---------------------------------
Existing origin remote URL ni change chestundi.

Manam:
HTTPS remote
    ↓
SSH remote

ki change chesam.


HTTPS:
git push appudu username/token authentication
avasaram ravachu.

SSH:
SSH key pair use chesi GitHub authenticate chestundi.

Important:
Private SSH key ni eppudu GitHub repository,
notes, chat, email or public place lo share cheyyakudadhu.
